# Security policy

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/tdb-project/tdb-connectors/security/advisories/new)
or by email to hello@tdb.jiracorp.co.in. Please don't open a public issue.

These connectors hold your TDB API key only in your operating system's secure
credential store, and send it only to the TDB server you configure. Supported
versions: the latest release.
